# Antigravity Meta-Skill Factory

## 🧬 Conceptual Essence
This is not a functional skill, but a **Generative Engine**. Its purpose is to observe gaps in the system's capabilities and autonomously create the necessary `SKILL.md` files, directory structures, and boilerplate scripts to fill those gaps.

## 🛠️ Generative Modules

### 1. Skill Architect (`skill-blueprint`)
- **Action:** Analyze a high-level user request (e.g., "I want to automate SEO auditing") and draft a comprehensive `SKILL.md` with YAML metadata.
- **Goal:** Standardize the "Antigravity Style" of skill documentation.

### 2. Meta-Prompting Engine (`prompt-synth`)
- **Action:** Autonomously craft specialized system prompts and instructions for new skills.
- **Logic:** Uses iterative feedback to refine the "Tone of Voice" and technical accuracy of the prompts.
- **Outcome:** Highly optimized instructions that reduce hallucinations and increase execution speed.

### 3. Skill Ingestor & Installer (`skill-ingest`)
- **Action:** Parse third-party skills (GitHub repos, community folders) and adapt them to the Antigravity architecture.
- **Goal:** Safely "install" external knowledge by auditing code for SaaS dependencies and wrapping them in sovereign local bridges.

### 4. Global Skill Deployer (`skill-globalize`)
- **Action:** Promote local project-level skills to the `C:\Users\tuUsuario\.agents\skills` global directory.
- **Outcome:** Decouples intelligence from a single folder, making Antigravity's capabilities available to any future project or workspace.

### 5. Boilerplate Synthesizer (`script-boilerplate`)
- **Action:** Generate the initial Python or Node.js scripts needed to support the new skill.
- **Logic:** Follows the project's sovereign architecture (using local MCPs, `.env` for secrets, and `07_Automation_n8n` for storage).

### 6. Capability Auditor (`skill-validation`)
- **Action:** Verify that the newly created skill doesn't conflict with existing ones and that its directory structure is Git-ready.

## 📊 Self-Expansion Protocol
1. **Identify Need:** User requests a complex function not covered by current skills.
2. **Drafting:** The Meta-Skill generates the folder in `.agents/skills/`.
3. **Refinement:** The agent (Antigravity) iterates on the generated code until it meets the PhD-level standard.
4. **Acquisition:** The new skill is indexed and becomes available for all future workflows.

## ⚠️ Safety Guardrails
- **Sovereignty Check:** All generated skills must strictly use local or private cloud infrastructure. No generated skill shall default to third-party SaaS dependency (Relevance/Zapier) without explicit user override.
