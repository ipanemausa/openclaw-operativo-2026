# 🔌 Open-Weight & Local AI Ecosystem Hub (Standard LeJavi & DeepSeek Harness)

Este plugin empaqueta todos los motores de lenguaje de código abierto, ejecutores locales y herramientas de IA de la descripción del curso LeJavi.

## 🗂️ Registro Completo de Herramientas MCP Autorizadas

1. **`query_deepseek_harness_v4_v5`**: Orquestación DeepSeek Harness V4 / V5 y DeepSeek Studio Chat para desarrolladores.
2. **`query_deepseek_r1`**: Razonamiento lógico profundo y matemática avanzada (`deepseek-reasoner`).
3. **`query_deepseek_v3`**: Inferencia ultra-rápida MoE y generación de código (`deepseek-chat`).
4. **`query_qwen_2_5`**: Inferencia de alta fidelidad JSON determinista y código multilingüe (Qwen 2.5 72B & Coder).
5. **`query_orca_model`**: Modelos de razonamiento paso a paso explicativo (Orca 2 / Orca Mini).
6. **`query_local_ollama`**: Inferencia offline privada (Ollama `http://localhost:11434` con Llama 3, Qwen 2.5, DeepSeek R1).
7. **`query_lm_studio`**: Conector con el servidor local de LM Studio (`http://localhost:1234/v1`).
8. **`query_jan_ai`**: Conector con la suite offline Jan AI (`http://localhost:1337/v1`).
9. **`query_anything_llm`**: Búsqueda vectorial RAG local en workspaces de Anything LLM (`http://localhost:3001/api/v1`).
10. **`trigger_comfyui_workflow`**: Invocación de workflows de generación de imagen/video en ComfyUI (`http://localhost:8188`).
