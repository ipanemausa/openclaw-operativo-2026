# 🦙 Ollama Local Engine Plugin

Este plugin conecta directamente Antigravity IDE con tu servidor local de **Ollama** (`http://localhost:11434`).

## 🗂️ Herramientas MCP Habilitadas

- `ollama_generate`: Genera texto plano usando cualquier modelo local (Llama 3, Qwen 2.5, DeepSeek R1 local, Orca).
- `ollama_chat`: Mantiene conversaciones multi-turno estructuradas offline.
- `ollama_list_models`: Consulta todos los modelos descargados en la GPU/CPU local.
